# 麻雀の危険牌予測モデル（機械学習）

## プロジェクト概要
約510万件の打牌ログデータを活用し、不完全情報ゲームである麻雀における意思決定の最適化（放銃回避）を目的とした予測モデルです。

## 使用技術
- Python
- LightGBM（勾配ブースティング決定木）
- Pandas / NumPy
- Google Colaboratory

## 工夫した点・実装の詳細
1. **データの不均衡（クラス不均衡）への対応**
   - 全データのうち放銃（当たり）データが極端に少ないため、アンダーサンプリングを実装。
   - 放銃データと安全データの比率を最適化（1:1〜1:2）することで、モデルのバイアスを解消しました。
2. **問題の再定義**
   - 当初取り組んだSVR（回帰）による点数予測から、実戦での意思決定に即した「危険か安全か」の2値分類へ変更。
3. **アルゴリズムの選定**
   - 大規模な構造化データに対して高速かつ高精度なLightGBMを採用しました。

## 結果
- 危険牌の判別精度：**約77.0%**（検証データセットにおいて）
